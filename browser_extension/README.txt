JARVIS Local Browser Link

This optional Edge/Chrome extension pairs a normal browser tab with the JARVIS
Windows app running on the SAME PC. It is not part of the public web version
and it never accepts the Ollama sharing code.

Install in Microsoft Edge
1. Start the installed J.A.R.V.I.S. app from the Windows Start menu.
2. In Edge, open edge://extensions.
3. Turn on Developer mode.
4. Click Load unpacked and select this browser_extension folder.
5. Open the JARVIS extension icon.
6. In JARVIS, open Settings -> Server -> Pair a Normal Browser and copy the
   Browser pairing code.
7. Paste that pairing code into the extension and click Connect.

After pairing, Settings -> Browsing -> External sends research to this normal
browser. A "find me" request can open a site/search and automatically follow a
visible result link; MakerWorld requests go directly to MakerWorld's model
search and click a model result. Manual browser-control commands still use the
normal approval flow. The extension never sends browser control through the
public web link. When no pairing code is saved, it stays idle.
